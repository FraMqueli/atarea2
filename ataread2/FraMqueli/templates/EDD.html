What is an ordered sequence?

A sequence of elements is ordered (not decreasing in this case) if it is true that \( x_1 \leq x_2 \leq ... \leq x_n \).

C example of Selection sort (the video is selection sort in place)

                    
void selection_sort(int *unordered_list, int unordered_size, int **ordered_list, int *ordered_size) {
    int j = 0;
    *ordered_list = (int*)malloc(unordered_size * sizeof(int));
    *ordered_size = 0;
    while (unordered_size > 0) {
        int min = unordered_list[0];
        int id = 0;
        for (int i = 1; i < unordered_size; i++) {
            if (unordered_list[i] < min) {
                min = unordered_list[i];
                id = i;
            }
        }
        (*ordered_list)[j++] = min;
        (*ordered_size)++;
        for (int i = id; i < unordered_size - 1; i++) {
            unordered_list[i] = unordered_list[i + 1];
        }
        unordered_size--;
    }
}

What can we say about the last algorithms?

Is it correct? What does it mean for an algorithm to be correct? For us, an algorithm will be considered correct if it finishes in a finite number of steps and achieves its intended purpose. In this case, that means ordering the elements in the array.
One method to prove that an algorithm is correct is by induction:

Induction

*) Is needed a base case: that is true for the first case or the n-first cases (strong induction).
*) Inductive step: If it is true for the case \(n = k\) (inductive hypothesis), then it is true for the case \(n = k + 1\).

Induction on minsort (not mathematically formal)

*) Base case: The first value is deleted from the original list and written on the ordered list (unique value on the ordered list).
*) Inductive hypothesis: the first k-values selected hit the rule (min value on the array) and are well written on the ordered list.
*) Demonstration: Using the inductive hypothesis, we can know that if we get the next value (\(k + 1\)) this will be the minimum value on the unordered list, then, by adding this value to the ordered list, that list will have the smaller values of the original unordered list. In other words, this value will be the largest value on the ordered list, because we are expecting that the k-steps were correct.

What can we say about the last algorithms? (2)

What is its complexity? First, the complexity is related to how many steps will be needed to do the task. We have the worst case, average case, and best case. And also can represent the memory usage that will be needed. Normally the time spent (or steps used) is expressed in terms of \(O (n)\) and the memory usage in terms of \(S(n)\).
So, what is its complexity? First, when we find the first min number we have to search for all the values of the array (\(O(n)\)) but next we have to do it for all \(n\) numbers.
